# Frame-Animation-Notation-Basic-Script-FANBS-
A small system to help you be more organized when animating with ASCII art

## 🚀 Installation
```bash
npm install fanbs
```
To determine the time, use "/" followed by the time, for example, 1 second is equal to 1000, so it would be "/1000".
To add frames, we could give them a name with: [name], then in parentheses "{ }" we can add our drawing.



/1000

Something to keep in mind is that anything else will be ignored, just like this message ;)

[frame1] {
\(O_O)/ \(*_*)/
}

Since the speed never changed, it remains the same, that is, 1 second.

[frame2] {
/(O_O)\ /(*_*)\
}

{
The name is not required {
/(O_^)\ /(*_*)\
}
/2500 We changed the speed to 2.5 seconds
 {
/(O_^)\ /(*_*)\
}
